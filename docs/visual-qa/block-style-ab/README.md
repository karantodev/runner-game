# Structural Block Style A/B

Both captures use seed `42`, frozen after `360` debug steps.

- `block-style-2d.png` — delivered pixel-art sprites.
- `block-style-3d.png` — Canvas-only 3D-like voxel primitives.

## Switches

- URL: `?blockStyle=2d` or `?blockStyle=3d`
- Runtime: press `Y`
- Debug panel: `Toggle 2D / 3D Blocks`

The default remains `2d`. The voxel mode intentionally affects only
modular structures: grass cubes, platforms, steps, stone walls, purple
bricks and question blocks. Spawn positions, collisions and gameplay
timing stay unchanged.
