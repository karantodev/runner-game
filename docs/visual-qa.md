# Visual QA

1. Start the local preview with `node server.mjs`.
2. Open `/dev.html` for the module-entry build or `/` for the synced root build.
3. Verify there are no runtime errors in the browser console.
4. Check the HUD, sprites, and scrolling scene for obvious layout or rendering regressions.

For debug-run capture, use the local debug controls exposed by the runtime when debug mode is enabled.
